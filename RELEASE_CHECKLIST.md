# Release checklist

- [ ] Update the version in package.json.
- [ ] Review the changelog or release notes.
- [ ] Run `npm test` locally.
- [ ] Ensure the GitHub Actions workflows pass.
- [ ] Create and push the release tag, for example `git tag v1.0.1 && git push origin v1.0.1`.
- [ ] Verify the published package on GitHub Packages.
