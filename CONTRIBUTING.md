# Contributing

Thanks for helping improve kv3-js.

## Development

1. Install dependencies with `npm install`.
2. Run the test suite with `npm test`.
3. Make your changes and add or update tests when behavior changes.

## Pull Requests

- Keep changes focused.
- Update documentation when public behavior changes.
- Ensure tests pass before submitting.

## Maintenance

- Dependabot will open weekly dependency update PRs.
- Follow the release checklist in RELEASE_CHECKLIST.md before publishing a new version.
